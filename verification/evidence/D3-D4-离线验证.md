## D3 受控 AI（ADR-0011）

- 识别只产生候选：Job＋outbox 同事务；Worker 条件认领（租约＋fencing）；每 Job 至多 2 次模型调用（先持久化计数）；格式错误不付费重试。
- 调用模型前与发布候选时均复核发起人身份与成员关系；发布事务同时校验 fencing、租约、分类目录版本。
- 严格解析：截断、重复键、混合文本、多围栏、未知字段、NaN 均拒绝；语义校验后未知分类改为“待分类”并标注“请核对”，无证据金额保持为空。
- 照片模型输入为去元数据的 JPEG 副本（EXIF／GPS 不外发）。
- 候选确认绑定显示内容摘要（字段＋版本＋当下汇率快照）；≤10 条同事务全有或全无；分类停用、汇率修正后旧摘要失效（candidate_stale）。

## D4 飞书（ADR-0013）

- 协议要点已从官方文档核实：签名、AES-256-CBC 解密、message_id 去重、卡片回调 3 秒与 token 规则、发送 uuid 1 小时去重、资源下载接口。
- 入口：签名 → 时间戳 ±5 分钟 → 解密 → token → app_id／tenant_key 白名单 → event_id 去重；未绑定、群聊、机器人消息不调用模型、不下载资源。
- 一次性绑定码（只存哈希，10 分钟，单次）；改密后绑定暂停，重新绑定恢复。
- 图片单发即识别；文字须“回复该图片”才合并，且只能关联本人发送的图片。
- 卡片内编辑（表单、一级分类刷新二级选项）、逐条／全部确认、删除、取消；动作 ID 由服务端按（批次、候选、版本、动作）确定性生成，重复点击命中同一回执。
- 交付经 outbox：未知结果在 uuid 去重窗口内以同一 uuid 重试；失败有限重试后标记 failed；任何交付结果都不改变入账。

## 测试中发现并修复的问题

- 测试隔离：共享表中其他测试遗留的 outbox／公共分区回复被处理，导致替身模型或失败注入被“借用”；处理函数增加家庭／open_id 过滤（仅本地与测试使用）。
- 评估工具评分把“漏掉候选”计入正确数；改为各关键字段计错。
- 候选标题金额未按币种位数显示；改用服务端折算预览中的格式化金额。

## 覆盖限制

- 替身模型的结果不代表真实识别质量；真实 Bedrock 比较（QUAL-01／02、AI-06）因缺少目标账户凭证**受阻**。
- 飞书只经合成回调与替身验证；URL 验证结构、卡片 JSON 2.0 字段、租户范围、3 秒时限（FS-06）均未真实核实。
