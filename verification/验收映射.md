# 验收映射

日期：2026-10-04（D0 建立；D1–D5 更新；D3 真实模型评估、D6 离线准备更新）。状态只能使用：**未实现／已实现待验证／离线通过／真实通过／受阻**。证据层级：静态＝契约或代码检查；离线＝合成数据本地测试（DynamoDB Local 等替身）；真实＝真实云服务／平台；部署＝生产环境读回。

验收 ID 来自私人《验收标准.md》，本仓库只引用 ID；ADR 新增的 ID 标注来源。完整 ID 清单见 [acceptance_ids.txt](acceptance_ids.txt)，`scripts/check_contracts.py` 校验本表覆盖全部 ID 与全部 OpenAPI operationId。

## 0. 证据记录格式

每条证据（写入 `verification/evidence/`，私人真实数据只留私有副本）至少包含：

| 字段 | 内容 |
|---|---|
| 验收 ID 与结论 | 断言的可观察性质 |
| 证据层级 | 静态／离线／真实集成／部署验收／持续运行 |
| 版本绑定 | commit 或 artifact 摘要、配置、Prompt／模型／Schema 版本、种子版本 |
| 场景 | 输入类别（合成／获准私有）、注入的故障、预期状态与副作用 |
| 独立核对 | 如何不依赖接口响应读回权威状态（例如直接查询表项、统计账目条数） |
| 实际结果 | 通过／失败／受阻／未运行，命令与输出摘要 |
| 覆盖与限制 | 未覆盖的身份、格式、语言、负载或失败路径 |

运行、质量、安全、业务提交、外部交付分别报告；本地替身结果最高只能标“离线通过”。
