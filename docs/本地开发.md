# 本地开发

## 前置

- uv（管理 Python 3.12，自动下载）
- Node.js ≥ 22 与 pnpm 11
- Docker（D1 起运行 DynamoDB Local）

## 安装

```bash
uv sync                 # Python 依赖（uv.lock）
pnpm install --frozen-lockfile   # 前端与 CDK（pnpm-lock.yaml）
```

## 检查（D0）

```bash
uv run python scripts/check_contracts.py   # OpenAPI／模型 Schema／种子／验收映射一致性
uv run pytest                              # 契约测试
pnpm --filter @family-ledger/frontend gen:api   # 由 OpenAPI 生成前端类型
pnpm -r run check                          # TypeScript 类型检查
```

或一次执行：`scripts/check.sh`。

## 本地数据库（D1 起）

```bash
docker compose up -d          # DynamoDB Local，端口 8000，数据保存在 .local-data/dynamodb
uv run pytest tests/integration   # 每次测试会话建独立表，结束后删除
LEDGER_RESTART_TEST=1 uv run pytest tests/integration/test_restart_readback.py  # 重启读回
```

集成测试在 DynamoDB Local 不可用时跳过；D1 的验收证据要求它们实际运行。

## 运行模式

`LEDGER_ENV=local` 时才允许本地身份、fake 模型、fake 飞书与 fixture 汇率（ADR-0007）。缺省视为生产并要求全部真实配置。本地替身结果不作为真实集成证据。



## 运行网站（D2 起）

```bash
docker compose up -d
export LEDGER_ENV=local DYNAMODB_ENDPOINT=http://localhost:8000 \
       LEDGER_TABLE=ledger-dev LEDGER_DELETION_TABLE=ledger-dev-journal \
       LEDGER_ALLOWED_ORIGINS=http://localhost:5173
uv run python -m ledger.local.bootstrap --admin <登录名> --name <显示名>   # 首次：建表、币种、合成汇率、系统管理员（临时密码只打印一次）
uv run python -m ledger.local.server        # API：http://localhost:8787
pnpm --filter @family-ledger/frontend dev    # 网站：http://localhost:5173
```

忘记本地临时密码：`uv run python -m ledger.local.reset_password <登录名>`（同样的环境变量）。

浏览器端到端测试（使用本机 Chrome，独立 `ledger-e2e` 表）：`cd frontend && pnpm exec playwright test`；需要更新截图证据时加 `SAVE_SCREENSHOTS=1`。
