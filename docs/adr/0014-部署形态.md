# ADR-0014 部署形态与权限边界

日期：2026-10-04　状态：已采纳（代码与本地合成）；真实部署待授权　依据：架构 §1／§4.2／§8／§9、ISE-027／028／030

## 决定

1. **同源访问**：CloudFront 一个域名同时服务静态站（S3＋OAC）与 `/v1/*`（转发 HTTP API，缓存禁用，转发除 Host 外的请求头）。取代架构 §9.2 的独立 API 子域名：refresh cookie `SameSite=Strict` 与前端相对路径直接可用，无需 CORS，少一张证书与一条 DNS 记录。
2. **按入口拆函数，共用一个制品**：`Api`（业务）、`AuthAdmin`（`/v1/auth/*`、`/v1/admin/*`、`/v1/me/password`，唯一持有 Cognito Admin 权限）、`FeishuCallback`、`Worker`（唯一持有 `bedrock:InvokeModel`，限定模型 ARN）、`Relay`（Streams＋5 分钟兜底，唯一可发 SQS）、`Maintenance`（清理、交付兜底、预算检查，唯一可删照片版本）。
3. **arm64＋Python 3.12**，依赖按 `aarch64-manylinux_2_28` 预编译 wheel 打包（Lambda python3.12 为 Amazon Linux 2023）。
4. **制品绑定**：`scripts/build_lambda.py` 生成确定性 zip 与 manifest（commit、锁文件摘要、制品摘要）；`scripts/verify_artifact.py` 为发布门禁；Lambda 环境变量携带 commit 与摘要，`GET /v1/health` 读回。部署工作流只下载 CI 上传的制品，不本地重建。
5. **数据保留**：两张表 `DeletionProtection`＋`RemovalPolicy.RETAIN`＋PITR 35 天；照片桶版本化，非当前版本 35 天过期（与 PITR 窗口一致，删除日志保证不复活）；导出桶 7 天过期；所有桶屏蔽公开访问、强制 TLS。
6. **秘密**：会话签名密钥由 Secrets Manager 生成；飞书凭证 Secret 由人工在控制台写入 JSON。代码、CI 输出与日志不含秘密值。
7. **预算**：`AWS::Budgets::Budget` 按 `user:Project$family-ledger` 标签过滤，80%／100% 发 SNS（可订阅备用邮箱）；应用内估算告警另行发飞书。超额只通知。

## 已知限制（如实记录）

- **DynamoDB IAM 不能按排序键前缀授权**：所有函数对业务表有读写权限。“识别 Worker 不能创建正式账目”由代码路径保证（Worker 不含任何入账调用），不是 IAM 强制。若需更强隔离，可把候选移到独立表并只授予 Worker 该表权限（成本：确认事务需跨表）。
- 当前所有函数都能读取飞书 Secret（runtime 统一构建）；后续可按函数拆分构建以收窄。
- `cdk synth` 只证明模板可生成；证书 DNS 验证、OIDC 角色信任策略、预算币种、Bedrock 模型访问均需真实部署核实。

## 补充：冷启动（2026-10-05 实测后调整）

- 512 MB 时网站函数冷启动 5～6.5 秒，首屏并发 5～7 个请求，各自冷启动，表现为长时间“加载中”；飞书卡片回调超过 3 秒限制。
- 调整：Api／AuthAdmin／FeishuCallback 改为 1769 MB（1 个完整 vCPU）；制品内契约预转 JSON；S3、飞书、模型客户端首次使用时才创建；每 5 分钟预热（Api 4 个实例、AuthAdmin 2 个、FeishuCallback 1 个，hold 0.8 秒使预热落在不同实例）。
- 实测：冷启动约 2 秒（初始化 0.9～1.1 秒＋首个请求约 1 秒），热请求端到端 0.1～0.2 秒。
- 费用调整（同日，用户要求）：预热只在白天（UTC 18:00–10:59＝新西兰 07:00–23:59 夏令时），hold 由 0.8 秒降为 0.3 秒，预计由约 1 美元／月降到约 0.25 美元／月；不采用降低到 10 分钟一次（空闲实例回收时间未公开，常见 5～15 分钟，间隔加长会频繁失效）。仍低于 SnapStart 与预置并发的费用。
- 重新判断：使用人数或并发增加导致预热实例不够时，再评估合并首屏接口或预置并发。
