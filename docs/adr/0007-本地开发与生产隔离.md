# ADR-0007 本地开发环境与生产隔离

日期：2026-10-04　状态：已采纳

## 决定

- 运行模式由 `LEDGER_ENV` 决定：`local` 或 `prod`（以及将来 `staging`）。默认缺省视为 `prod` 并要求全部真实配置，缺失即启动失败。
- `local` 模式提供：DynamoDB Local（Docker）、本地 S3 替身（文件目录＋签名模拟）、本地身份服务（本地密钥签发与 Cognito 同形 JWT，密码哈希仅存本地库）、fake 模型（基于规则的确定性输出）、fake 飞书（录制请求、模拟回调签名）、fixture 汇率。所有本地替身位于 `backend/src/ledger/local/`，界面顶部显示“本地开发模式”横幅。
- 生产构建打包脚本排除 `ledger/local/` 整个包；启动时若 `LEDGER_ENV=prod` 而导入了 local 模块或 issuer 不是配置的 Cognito issuer，立即失败。CI 增加检查：生产 artifact 中不存在 `ledger/local`。
- 本地替身不作为 Cognito、S3、IAM、Bedrock、飞书或 DynamoDB 生产事务的验收证据（验收映射中证据层级最多为“离线通过”）。
