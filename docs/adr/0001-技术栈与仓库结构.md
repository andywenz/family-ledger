# ADR-0001 技术栈与仓库结构

日期：2026-10-04　状态：已采纳

## 决定

- 仓库根目录即项目根（本地 `ledger/`），私人交接包 `ledger需求文档集/` 留在原处并被 `.gitignore` 排除，不进入版本历史。
- 后端：Python 3.12（Lambda 当前支持的运行时；本机 3.14 不用于产物），uv 管理，`uv.lock` 锁定。包路径 `backend/src/ledger/`，分 `domain／application／adapters／handlers／local` 五层。HTTP 路由使用由 OpenAPI 驱动的自有分发器（`ledger/http/app.py`，D2 起取代原计划的 powertools，避免路由与契约两处维护），请求体直接按 OpenAPI Schema 校验，金额全部 `decimal.Decimal`／整数分值。
- 前端：TypeScript＋React 19＋Vite，React Router，TanStack Query；API 类型由 `contracts/openapi.yaml` 经 openapi-typescript 生成。图表使用自绘 SVG（只显示后端结果），不引入大型图表库。
- 基础设施：AWS CDK（TypeScript），与前端同一 pnpm workspace，`pnpm-lock.yaml` 锁定。
- 测试：pytest＋hypothesis（领域不变量），moto 仅用于适配器形状测试；事务与并发语义用 DynamoDB Local（Docker）验证，生产行为另行真实验收。浏览器旅程用 Playwright。

- TypeScript 固定在 5.9.x：TypeScript 7（Go 原生实现）不提供 openapi-typescript、ts-node 等依赖的 JS 编译器 API。待生态支持后再评估升级。

## 理由

与交接建议一致；单一 Python 业务核心供 HTTP、队列、Streams、定时入口共用，避免两套金额实现。

## 影响

本机需 Docker 运行 DynamoDB Local。CDK CLI 通过 workspace 依赖调用，不要求全局安装。
