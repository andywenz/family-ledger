# ADR-0005 用户显示名

日期：2026-10-04　状态：已采纳（用户决定）

## 决定

- User 增加 `display_name`（1–24 字符，可重复，用户可自行修改），用于 Dashboard／导出“录入人”、成员列表、飞书卡片。
- 登录名（唯一、不区分大小写）只用于登录；内部固定 `user_id` 用于全部归属。
- 显示名在查询时按 `user_id` 解析，改名后历史记录显示新名，不复制到每条账目。导出文件写入导出时的显示名。
- 新账号的初始显示名由系统管理员创建时填写，默认与登录名相同。

## 影响

新增 `PATCH /me/profile`；`GET /families/{fid}/members` 与账目响应携带 `created_by_display`。
